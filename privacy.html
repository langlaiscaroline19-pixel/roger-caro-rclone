Politique de confidentialité

Roger-Caro-Rclone est une configuration personnelle de Rclone sur macOS.

Elle sert à copier des fichiers sélectionnés de Microsoft OneDrive vers Google Drive.

L'accès à Google Drive utilise OAuth avec l'autorisation drive.file, limitée aux fichiers utilisés avec cette application.

Les autorisations et jetons de connexion sont conservés localement dans la configuration Rclone. Les fichiers copiés sont conservés dans le Google Drive du propriétaire.

Cette configuration ne comporte pas de serveur applicatif personnel collectant les documents. Les fournisseurs cloud traitent les données selon leurs propres politiques.

Le propriétaire peut révoquer l'accès depuis les paramètres de son compte Google.

Cette page ne donne accès à aucun fichier personnel et ne contient aucun identifiant secret.
